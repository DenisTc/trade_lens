# TradeLens · День 4: чарт и экран пары Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Свечной движок на `CustomPainter` в пакете `chart` (свечи, объём, кроссхейр, зум, пан, режим без объёма и с произвольной гранулярностью), экран пары с графиком, стаканом top-10 и лентой сделок, golden-тесты и бенчмарк перерисовки.

**Architecture:** `chart` не зависит от feature-слоя и от `domain`: принимает `ChartCandle` на `double` (граница конверсии из `Decimal` одна, в маппере фичи). Два painter-а: свечи+объём и слой кроссхейра, чтобы движение пальца не перерисовывало свечи. `ChartViewport` хранит индекс первой видимой свечи и ширину свечи; зум меняет ширину, пан меняет индекс, новая свеча «прилипает» к правому краю, если пользователь не отматывал. Шкала цены по видимому диапазону, метки через `TextPainter` с кэшем. Экран пары живёт в `features/markets`, провайдеры свечей/стакана/ленты в `features/shared`.

**Tech Stack:** Flutter CustomPainter, GestureDetector (scale), golden_toolkit-free golden через `matchesGoldenFile` + `flutter_test_config.dart` с загрузкой шрифтов, Riverpod 3.

**Spec:** `docs/spec/tradelens-prd-tid-v1.2.md`, разделы «Чарт на CustomPainter», «Функции» → Свечной график, Стакан и лента, «Тесты» → Golden, «План по дням» → День 4.

## Global Constraints

- «Пакет `chart` без зависимостей от feature-слоя … Публичный API: `CandleChart(candles, interval, overlays, onCrosshair)`».
- «Два painter-а … `shouldRepaint` по идентичности списка и viewport. Новая свеча с тем же `openTime` обновляет последнюю, а не добавляет».
- «Viewport хранит индекс первой видимой свечи и ширину свечи в пикселях … прилипает к правому краю, если пользователь не отматывал».
- «Decimal только в данных, в painter уже double. Граница конверсии одна, в мапере viewport».
- «Golden-тесты на три состояния: пусто, 50 свечей, 500 свечей с кроссхейром. Бенчмарк перерисовки в `test/benchmark`. Режим без объёма и с произвольной гранулярностью».
- «История 500 свечей через REST, дописывание через WS kline-стрим». «Лента последних 30 сделок». Стакан: «локальное состояние заменяется целиком».
- «Golden-тесты только через fvm flutter test, шрифты грузятся в flutter_test_config.dart».

### Task 1: модель и viewport (`packages/chart`)

**Files:** `lib/src/model.dart` (`ChartCandle`, `ChartInterval`), `lib/src/viewport.dart` (`ChartViewport`), `lib/src/series.dart` (`CandleSeries` с upsert по `openTime`), tests.

- [ ] `ChartCandle({openTime, open, high, low, close, volume?})` на `double`; `CandleSeries.upsert(candle)` заменяет свечу с тем же `openTime`, иначе добавляет в конец (и сортирует при вставке в середину).
- [ ] `ChartViewport({firstIndex, candleWidth, minWidth: 2, maxWidth: 40})`: `visibleCount(width)`, `zoomAt(factor, focalIndex)`, `pan(dxPixels)`, `clamp(total)`, `stickToEnd`; `priceRange(candles)` по видимым.
- [ ] Тесты: upsert, зум вокруг фокуса, пан с границами, прилипание при добавлении.

### Task 2: painters и виджет

**Files:** `lib/src/candle_painter.dart`, `lib/src/crosshair_painter.dart`, `lib/src/axes.dart` (шкалы, `TextPainter` кэш), `lib/src/candle_chart.dart` (виджет с жестами), `lib/chart.dart`.

- [ ] `CandleChart({candles, interval, showVolume, granularityLabel, onCrosshair, theme})`: `GestureDetector` с `onScaleStart/Update` (пан по одному пальцу, зум по двум), `onLongPress`/drag → кроссхейр.
- [ ] Свечи: тело up/down цветами темы, фитили, объём в нижних 20 % с максимумом по видимым; шкала цены справа с 5 метками, шкала времени снизу по интервалу (или гранулярности для `auto`).
- [ ] `shouldRepaint` по identity серии и viewport.
- [ ] Widget-тест: пинч меняет `candleWidth`, драг меняет `firstIndex`.

- [ ] Три golden: пусто, 50 свечей, 500 свечей с кроссхейром; светлая и тёмная тема (6 файлов).

### Task 4: провайдеры и экран пары

**Files:** `packages/features/shared/lib/src/providers/pair.dart` (`candlesProvider(instrument, interval)` = REST история + kline-стрим с upsert; `orderBookProvider(instrument)`; `tradesProvider(instrument)` последние 30), `packages/features/markets/lib/src/pair_screen.dart`, `order_book_view.dart`, `trade_tape.dart`, `interval_selector.dart`, `apps/mobile/lib/screens/pair_screen.dart`, tests.

- [ ] `candlesProvider`: `Notifier` family; `build` грузит `klines(limit: 500)` (или CoinGecko OHLC), затем слушает `klineStream` и делает upsert; при `Capabilities.klineStream == false` только история; ошибка сети при пустой истории → `AsyncError`, при непустой остаётся данными.
- [ ] Экран: селектор интервалов (скрыт при `intervals == {auto}`), чарт, стакан (скрыт без capability), лента (скрыта без capability), `DataSourceBadge`. При потере сети график не пустеет: последний снапшот + точка состояния.
- [ ] Тесты: widget с фейковым источником (три состояния, скрытие стакана в prices-only), golden экрана пары.
