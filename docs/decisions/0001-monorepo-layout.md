# ADR-0001 · Monorepo на pub workspaces + Melos, пакеты по слоям

Дата: 2026-09-08 · Статус: принято

## Контекст

TradeLens это showcase для трёх читателей: рекрутер, тимлид, интервьюер.
Тимлид смотрит структуру пакетов пять минут, интервьюер просит открыть файл.
Структура должна объяснять архитектуру сама, без чтения кода.

## Решение

- Один репозиторий, pub workspaces (Dart 3.6+) для общего резолва
  зависимостей и Melos 8 для скриптов по пакетам. Конфиг Melos живёт в
  корневом `pubspec.yaml`, отдельного `melos.yaml` нет.
- Пакеты по слоям, направление зависимостей защищено тестом в
  `tooling/arch_test`, который читает pubspec-ы и импорты:

  | Пакет | Может зависеть от |
  |---|---|
  | `core` | ничего внутреннего |
  | `domain` | `core` |
  | `ws_client` | `core` |
  | `data_market` | `core`, `domain`, `ws_client` |
  | `data_local` | `core`, `domain` |
  | `chart`, `sdui` | `core` |
  | `ai_insights` | `core`, `domain` |
  | `features/*` | `core`, `domain`, `chart`, `sdui`; не другие features |
  | `apps/mobile` | всё |

- Feature-пакеты видят только интерфейсы из `domain` и чистые UI-пакеты.
  Реализации (`data_market`, `data_local`, `ws_client`, `ai_insights`)
  подключаются в `apps/mobile` через override Riverpod-провайдеров. Где
  объявляются сами провайдеры интерфейсов, решает ADR дня 3.
- Три архитектурных правила из спеки: направление зависимостей, запрет
  `double` в `domain`, запрет прямых HTTP-импортов (`dio`, `http`,
  `web_socket_channel`) из features и приложения.
- Корневой `pubspec.lock` коммитится (в workspace он один на все пакеты),
  CI выполняет `melos bootstrap --enforce-lockfile`, кэш pub ключуется его
  хешем, поэтому сборка одного коммита воспроизводима.
- Сгенерированные файлы (`*.g.dart`, `*.freezed.dart`, `*.drift.dart`) не
  коммитятся, CI генерирует их шагом `melos run generate` перед analyze.
- Flutter зафиксирован в `.fvmrc`, CI читает версию оттуда же, чтобы
  локальная и серверная сборки не расходились.

## Последствия

- Плюс: новый пакет обязан попасть в allow-list теста, иначе CI красный.
  Нарушение слоёв ловится до ревью.
- Минус: workspace требует, чтобы все пакеты резолвились одним набором
  версий. Конфликт версий транзитивных зависимостей решается в корне.
- Минус: без закоммиченного кода генерации IDE после clone показывает
  ошибки, пока не выполнен `melos run generate`. Записано в README.
