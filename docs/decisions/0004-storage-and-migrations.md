# ADR-0004 · Хранилище на Drift, деньги как TEXT, миграции с тестом

Дата: 2026-09-09 · Статус: принято

## Контекст

Портфель должен жить офлайн, оценка по последней котировке должна честно
называть время, а кэш свечей позволять открыть экран пары без сети. Спека
требует «реальную миграцию» v1→v2 с тестом, а не только создание схемы.

## Решение

- Drift с четырьмя таблицами: `positions`, `candle_cache`, `last_quotes`,
  `settings`. Одна база на приложение, `drift_flutter` для файла,
  `NativeDatabase.memory()` в тестах.
- Деньги и количества хранятся как `TEXT` и парсятся в `Decimal`. `REAL`
  потерял бы точность строки биржи; урок MOB-2174 из спеки.
- Схема v1 зафиксирована снимком `drift_schemas/drift_schema_v1.json`, v2
  добавляет `positions.note` через `onUpgrade`. Тест `migration_test.dart`
  вставляет строку в базу версии 1 (`DatabaseAtV1` из `drift_dev schema
  generate`), запускает миграцию, читает строку обратно и проверяет, что
  `note` появился пустым. Снимки схем и сгенерированные помощники
  коммитятся: они входные данные теста, а не артефакт сборки.
- `last_quotes` пишется из `quoteProvider` не чаще раза в 15 с на
  инструмент; оценка портфеля без живой котировки берёт сохранённую и
  показывает «на HH:mm» по самой старой использованной котировке.
- Кэш свечей ключуется по `sourceId + symbol + interval`, хранит последние
  500 и переписывается одной транзакцией батчем. Провайдер свечей отдаёт
  кэш сразу, сеть подменяет его и переписывает кэш; при ошибке сети кэш
  остаётся на экране, при пустом кэше ошибка показывается.
- Region resolution и ручной выбор источника лежат в `settings` как
  строки; DI приложения перестраивает живой стек при смене выбора.
- Drift читает unix-время как локальное; маппер приводит его к UTC, домен
  всегда в UTC.

## Последствия

- Плюс: миграция доказана тестом, а не обещанием.
- Плюс: провайдеры фич тестируются на in-memory фейках, Drift только в
  `data_local`.
- Минус: `TEXT` для денег исключает агрегаты в SQL; суммы считаются в
  Dart, что для 20 позиций ничего не стоит.
