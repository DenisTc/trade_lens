## Требует денег или чужого аккаунта (решение владельца)

Всё ниже упирается не в код, а во внешний сервис. Приложение работает без
этого, README честно называет границу.

- **Universal Links на iOS и App Links на Android по https.** Платформы
  читают файлы проверки из корня домена, а GitHub Pages отдаёт проект по
  пути `/trade_lens/` и не умеет менять заголовки; Apple при этом требует
  `application/json` для `apple-app-site-association`. Нужен свой домен
  (например, за Cloudflare) либо репозиторий `DenisTc.github.io`, второе
  закроет только Android. Решено 10.09.2026: домен не покупаем, схема
  `tradelens://` остаётся единственным входом. Файлы лежат в
  `docs/.well-known/` и переедут за пять минут, когда домен появится.
- **Отложенный диплинк** (параметр переживает установку из стора). Нужен
  SDK атрибуции: AppsFlyer Zero бесплатен на 12 000 конверсий и 12
  месяцев, дальше платный.
- **Пуши.** OneSignal бесплатен до 1 000 активных устройств в месяц; то же
  самое бесплатно и без лимита даёт Firebase Cloud Messaging, проект уже
  заведён. Строка в резюме отличается, техника нет.
- **Отпечаток релизного ключа в `assetlinks.json`.** Сейчас там ключ
  отладочной подписи, то есть проверяются только dev-сборки.
- **TestFlight.** Apple Developer, $99 в год.
